# Juno Augmented Navigation

This repository contains the ROS 2-based software stack for the **Juno Augmented Navigation** project.
It includes the nodes, launch files, and configuration needed to build and run the system in the supported development environment.

> **Important:** Follow the installation steps carefully.
> This project is currently developed for **Ubuntu 22.04** and **ROS 2**.

---

## Supported Environment

- **Ubuntu:** 22.04 LTS (Jammy Jellyfish) [Download](https://releases.ubuntu.com/jammy/)
- **ROS:** ROS 2 Humble Hawksbill [Documentation](https://docs.ros.org/en/humble/index.html)
- **Build system:** colcon
- **Python:** 3.10.12 [Download](https://www.python.org/downloads/)

---

## Dependency Overview

The project uses three different dependency groups:

1. **Standard Python library**
   - Examples: `os`, `sys`, `time`, `math`, `datetime`, `pathlib`, `argparse`, `glob`
   - These are included with Python and do **not** go into `requirements.txt`.

2. **Pip-installable Python packages**
   - These go into `requirements.txt`.
   - Based on the Python files in this repository, the pip dependencies are:
     - `python-can`
     - `opencv-python`
     - `matplotlib`
     - `numpy`
     - `pytrinamic`
     - `ultralytics`
     - `torch`
     - `torchvision`

3. **ROS 2 / system dependencies**
   - Examples: `rclpy`, `sensor_msgs`, `std_msgs`, `geometry_msgs`, `nav_msgs`, `tf2_ros`, `cv_bridge`, `launch`, `launch_ros`, `tf_transformations`
   - These should **not** be placed in `requirements.txt`.
   - They should be installed with ROS 2 tools and declared in `package.xml`.

4. **ZED SDK dependency**
   - `pyzed.sl` is part of the **ZED SDK Python API**.
   - It is **not** a normal PyPI dependency and should **not** be added to `requirements.txt`.

5. **Project-local modules**
   - Examples: `shared_objects.*`
   - These are internal modules from this repository or related project code and should **not** be added to `requirements.txt`.

## Installation

### 1. Clone this repository

```bash
cd path/to/your/ros2_ws/src
git clone https://github.com/AutonomousDrivingH2politO/AD-SEM
```

### 2. Install pip dependencies
From the repository root, run:
```bash
pip install -r requirements.txt
```
> **Note about PyTorch:** if this project needs CUDA-enabled PyTorch, install `torch` and `torchvision` using the command generated by the [official PyTorch install selector](https://pytorch.org/get-started/locally/) instead of the generic CPU-only pip flow.

### 3. Install ROS 2 dependencies
Make sure ROS 2 is installed and sourced, then install workspace dependencies with:
```bash
source /opt/ros/$ROS_DISTRO/setup.bash
rosdep install --from-paths .. --ignore-src -r -y
```

If you are running the command from the workspace root instead of from inside the repository folder, use:
```bash
source /opt/ros/$ROS_DISTRO/setup.bash
rosdep install --from-paths src --ignore-src -r -y
```

### 4. Install the ZED SDK Python API
If your setup uses the ZED camera, install the ZED SDK and the ZED Python API separately. This is required for:
`import pyzed.sl as sl`

### 5. Clone external repositories
- **TwinLiteNetPlus**: [Link](https://github.com/chequanghuy/TwinLiteNetPlus/tree/e0521920e110b374ae5f5343020ef2fc09bfa0eb)
- **ublox**: [Link](https://github.com/AutonomousDrivingH2politO/ublox/tree/665973146687b5e3a9fc85b48e60ec27c1c64202)
- **zed-ros2-examples**: [Link](https://github.com/stereolabs/zed-ros2-examples/tree/3ee3f69449b93413cb8f201e97fbe0bb19554709)
- **zed-ros2-wrapper**: [Link](https://github.com/AutonomousDrivingH2politO/zed-ros2-wrapper/tree/21f67d717e58987af8baf72f0a60159836b34a9e)
- **ntrip_client**: [Link](https://github.com/AutonomousDrivingH2politO/ntrip_client/tree/ca4de0dad0fae12fa6d8e9856a993eec5007ce89)
- **rtabmap**: [Link](https://github.com/introlab/rtabmap/tree/d11aa0a88149a2956973ef3c74cc98183a5c2767)
- **rtabmap_ros**: [Link](https://github.com/AutonomousDrivingH2politO/rtabmap_ros/tree/ede1acb90a62823b2e1092867db7577b72ba2e7c)

### 6. Build the workspace
From the ROS 2 workspace root, build the packages with:
```bash
colcon build
```
To build a specific package only:
```bash
colcon build --packages-select <package_name>
```

### 7. Source the workspace     
After building, source the workspace:
```bash
source install/setup.bash
```
*Note: If you open a new terminal, source ROS 2 and the workspace again before running commands.*

### 8. Running the project
Launch a package:
```bash
ros2 launch <package_name> <launch_file>.launch.py
```

Run a single node:
```bash
ros2 run <package_name> <node_name>

```

---

### Notes
- Follow the installation steps in the given order.
- Use **Ubuntu 22.04 LTS** to match the current ROS 2 environment.
- After major changes, rebuild the workspace and source `install/setup.bash` again.
- ROS 1 commands such as `catkin build`, `catkin_make`, and `roslaunch` are **not** used in this setup.
- `requirements.txt` is only for pip packages. It should not contain ROS 2 packages, standard-library modules, or project-local imports.
